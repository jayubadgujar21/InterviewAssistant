# Interview Assistant (AI Chat)

Interview Assistant is an AI-powered backend application built with **Spring Boot**, designed to help users practice interviews and get instant AI-generated responses.  
It leverages **OpenAI ChatGPT** to simulate realistic interview scenarios, provide feedback, and improve user preparedness.

## ✨ Features
- Ask interview questions and receive AI-generated answers
- Role-based question sessions (user/admin)
- Record and review past interview questions
- Lightweight REST API backend for integration with any frontend
- Supports multiple domains and question categories

## 🛠 Tech Stack
- **Java 17**
- **Spring Boot 3.x**
- **Spring Security (JWT)**
- **OpenAI ChatGPT API**
- **MySQL**
- **Maven**
